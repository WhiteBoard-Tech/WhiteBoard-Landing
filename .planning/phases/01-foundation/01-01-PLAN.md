  <action>
Create a new Astro project in the current directory (it's empty except for .planning/ and .claude/):

1. Initialize with `npm create astro@latest -- . --template basics --typescript strict --install --no-git` (use current directory, basics template, strict TypeScript)

2. Install Tailwind CSS v4 dependencies:
   `npm install tailwindcss @tailwindcss/vite`

3. Install Fontsource Inter variable font:
   `npm install @fontsource-variable/inter`

4. Update `astro.config.mjs` with this exact content:
```javascript
import { defineConfig } from "astro/config";
import tailwindcss from "@tailwindcss/vite";

export default defineConfig({
  i18n: {
    locales: ["en", "es"],
    defaultLocale: "en",
    routing: {
      prefixDefaultLocale: true,
      redirectToDefaultLocale: true,
    },
  },
  vite: {
    plugins: [tailwindcss()],
  },
});
```

5. Update `tsconfig.json` to add path aliases:
```json
{
  "extends": "astro/tsconfigs/strict",
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["src/*"],
      "@components/*": ["src/components/*"],
      "@layouts/*": ["src/layouts/*"],
      "@i18n/*": ["src/i18n/*"]
    }
  }
}
```

IMPORTANT: Do NOT use @astrojs/tailwind integration (deprecated for v4). Use @tailwindcss/vite directly in the vite plugins array as shown above.
  </action>
  <verify>
    - Run `npm run dev` - should start without errors
    - Check `package.json` contains astro, tailwindcss, @tailwindcss/vite, @fontsource-variable/inter
    - Check `astro.config.mjs` has i18n config and tailwindcss vite plugin
  </verify>
  <done>Astro dev server starts on localhost:4321 without errors</done>
</task>

```css
@import "tailwindcss";

@theme {
  /* Reset default colors, use only brand palette */
  --color-*: initial;

  /* Brand Colors - Black/White/Gray only */
  --color-white: #FFFFFF;
  --color-black: #000000;
  --color-gray-50: #FAFAFA;
  --color-gray-100: #F5F5F5;
  --color-gray-200: #E5E5E5;
  --color-gray-300: #D4D4D4;

  --color-gray-500: #737373;
  --color-gray-600: #525252;
  --color-gray-700: #404040;
  --color-gray-800: #262626;
  --color-gray-900: #171717;
  --color-gray-950: #0A0A0A;

  /* Typography - Premium Tech */
  --font-sans: "Inter Variable", ui-sans-serif, system-ui, -apple-system, sans-serif;
  --font-display: "Inter Variable", ui-sans-serif, system-ui, -apple-system, sans-serif;

  /* Font Sizes - Bold scale for premium feel */
  --text-xs: 0.75rem;
  --text-sm: 0.875rem;
  --text-base: 1rem;
  --text-lg: 1.125rem;
  --text-xl: 1.25rem;
  --text-2xl: 1.5rem;
  --text-3xl: 1.875rem;
  --text-4xl: 2.25rem;
  --text-5xl: 3rem;
  --text-6xl: 3.75rem;
  --text-7xl: 4.5rem;

  /* Line Heights */
  --leading-none: 1;
  --leading-tight: 1.25;
  --leading-snug: 1.375;
  --leading-normal: 1.5;
  --leading-relaxed: 1.625;

  /* Letter Spacing */
  --tracking-tighter: -0.05em;
  --tracking-tight: -0.025em;
  --tracking-normal: 0;
  --tracking-wide: 0.025em;

  /* Spacing - 4px base, geometric progression */
  --spacing: 0.25rem;

  /* Border Radius - Minimal/geometric */
  --radius-none: 0;
  --radius-sm: 0.125rem;
  --radius-DEFAULT: 0.25rem;
  --radius-md: 0.375rem;
  --radius-lg: 0.5rem;
  --radius-xl: 0.75rem;
  --radius-full: 9999px;

  /* Shadows - Subtle, premium feel */
  --shadow-sm: 0 1px 2px 0 rgb(0 0 0 / 0.05);
  --shadow-DEFAULT: 0 1px 3px 0 rgb(0 0 0 / 0.1), 0 1px 2px -1px rgb(0 0 0 / 0.1);
  --shadow-md: 0 4px 6px -1px rgb(0 0 0 / 0.1), 0 2px 4px -2px rgb(0 0 0 / 0.1);
  --shadow-lg: 0 10px 15px -3px rgb(0 0 0 / 0.1), 0 4px 6px -4px rgb(0 0 0 / 0.1);

  /* Transitions */
  --transition-fast: 150ms;
  --transition-DEFAULT: 200ms;
  --transition-slow: 300ms;
}

/* Base styles */
html {
  scroll-behavior: smooth;
}

body {
  font-family: var(--font-sans);
  -webkit-font-smoothing: antialiased;
  -moz-osx-font-smoothing: grayscale;
}
```

- Sets Inter Variable as the primary font family
- Establishes a type scale suitable for bold, premium tech aesthetic
- Uses 4px base spacing (standard)
- Minimal border radius for geometric feel
