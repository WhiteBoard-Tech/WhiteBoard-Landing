<task id="2" type="auto">
  <name>Create Hero component with flexible layout</name>
  <files>src/components/Hero.astro</files>
  <action>
Create Hero.astro following the research pattern for i18n-safe layouts:

```astro
---
import { Image } from 'astro:assets';
import { getLangFromUrl, useTranslations } from '@i18n/utils';
import CTAButton from './CTAButton.astro';
import heroImage from '@assets/images/hero-placeholder.svg';

const lang = getLangFromUrl(Astro.url);
const t = useTranslations(lang);
---

<section id="hero" class="min-h-[calc(100vh-4rem)] flex items-center px-4 sm:px-6 lg:px-8 py-12 lg:py-0">
  <div class="max-w-7xl mx-auto w-full">
    <div class="grid lg:grid-cols-2 gap-8 lg:gap-12 items-center">
      <!-- Text content - flexible container for text expansion -->
      <div class="max-w-xl lg:max-w-none">
        <h1 class="text-4xl sm:text-5xl lg:text-6xl font-bold tracking-tight text-black leading-tight">
          {t('hero.headline')}
        </h1>

        <p class="mt-6 text-lg sm:text-xl text-gray-600 leading-relaxed">
          {t('hero.subheadline')}
        </p>

        <div class="mt-10 flex flex-col sm:flex-row gap-4 sm:items-center">
          <!-- Primary CTA - most prominent -->
          <CTAButton href="#contact" variant="primary">
            {t('hero.cta.primary')}
          </CTAButton>

          <!-- Secondary CTA - visually subordinate text link with icon -->
          <a
            href="#video"
            class="text-gray-600 hover:text-black transition-colors duration-200 text-sm font-medium inline-flex items-center gap-2"
          >
            <span>{t('hero.cta.secondary')}</span>
            <svg class="w-4 h-4" fill="none" viewBox="0 0 24 24" stroke="currentColor" aria-hidden="true">
              <path stroke-linecap="round" stroke-linejoin="round" stroke-width="2" d="M14.752 11.168l-3.197-2.132A1 1 0 0010 9.87v4.263a1 1 0 001.555.832l3.197-2.132a1 1 0 000-1.664z" />
              <path stroke-linecap="round" stroke-linejoin="round" stroke-width="2" d="M21 12a9 9 0 11-18 0 9 9 0 0118 0z" />
            </svg>
          </a>
        </div>
      </div>

      <!-- Hero graphic - right side on desktop -->
      <div class="lg:order-last">
        <Image
          src={heroImage}
          alt="Tech partnership illustration"
          class="w-full h-auto"
          loading="eager"
        />
      </div>
    </div>
  </div>
</section>
```

Key design decisions:
- `leading-tight` on h1 handles multi-line wrapping for Spanish
- Flexible containers (no fixed widths) accommodate 20-30% text expansion
- Secondary CTA is text link style (not button) - visually subordinate
- Play icon indicates video content
- Grid layout with lg:grid-cols-2 for responsive design
- section has id="hero" for potential anchor linking
