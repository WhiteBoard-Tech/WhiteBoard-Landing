**Calendly URL:** Use placeholder: `https://calendly.com/whiteboard-co/30min`
(Will be replaced with actual URL before launch)

**Button implementation:**
```astro
<button
  type="button"
  onclick="Calendly.initPopupWidget({url: 'https://calendly.com/whiteboard-co/30min'}); return false;"
  class="inline-flex items-center justify-center px-8 py-4 text-base font-semibold text-black bg-white rounded hover:bg-gray-100 transition-colors duration-200 focus:outline-none focus:ring-2 focus:ring-offset-2 focus:ring-offset-black focus:ring-white"
>
  {t('contact.cta')}
</button>
```

**Key details:**
- Use `<button>` element (not anchor) since it triggers JS, doesn't navigate
- type="button" prevents form submission behavior
- onclick calls Calendly.initPopupWidget with the scheduling URL
- return false prevents any default behavior
- Inverted color scheme (white button on black background) for visual impact
- Focus ring accounts for black background (ring-offset-black)
  </action>
